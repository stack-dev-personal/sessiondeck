Fill this in during three days of real use. It satisfies the Phase 3 definition-of-done line "Used daily by you for three days with real sessions" and feeds Phase 5 (Atlas: projects, archive) and Phase 6 (Layouts). Every cell marked "(fill in)" is yours.

## 1. Running the board against the live hub

1. Start the hub on the dedicated box (it listens on `localhost:8787` when run locally).
2. Start the web app with mock mode off: `VITE_MOCK` unset or `0`. Dev server is `localhost:5173`.
3. Open Settings and enter the hub URL and your token. Reload; the header should show a connected state.
4. Start the probe on the laptop and open real Claude Code sessions. Cards should appear within 1 s of session start.
5. In Settings, opt in to browser notifications and to the sound, each separately and per state. Grant the browser permission when asked.
6. Press `c` to toggle compact mode; `Enter` opens the drawer, `Esc` closes it.
